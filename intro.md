# Plaud Pipeline — введение

> **TL;DR.** У вас часы записей с диктофона, видео-лекций или интервью. У вас нет времени их слушать и обрабатывать. Этот pipeline за минуты превращает каждый файл в **читаемый PDF**, **главу учебника** или **готовые метаданные для YouTube** — локально, на вашем железе, с любым LLM на выбор.

---

## Что это?

Open-source pipeline, который соединяет три слоя автоматизации, обычно сделанные плохо или платно:

1. **Сбор** — выгружает записи из вашего личного кабинета [Plaud](https://www.plaud.ai/) (или берёт `.wav/.mp3/.mov` из любой папки) **без облачных посредников**, через ваш собственный JWT-токен.
2. **Расшифровка** — локальный Whisper на CPU, NVIDIA GPU или Intel iGPU. **Никаких внешних транскрибаторов**, никаких загрузок ваших разговоров в чужие облака.
3. **Осмысление** — LLM (Claude, локальная Ollama — на выбор) превращает сырой транскрипт в структурированный документ по заранее заданному шаблону.

Финал — **готовые к использованию артефакты**: PDF с красивой типографикой, markdown для редактирования, оглавление, индекс.

## Что вы получите на выходе

### 1. Папка встреч за период

```
C:\_Dictophone\Записи с 05.06.2026 по 10.06.2026\
├── Стратсессия Радиофака — KPI и партнёрство с индустрией.mp3
├── Стратсессия Радиофака — KPI и партнёрство с индустрией.pdf      ⭐
├── Стратсессия Радиофака — KPI и партнёрство с индустрией.md
├── Стратсессия Радиофака — KPI и партнёрство с индустрией-transcript.txt
├── ... ещё 5 встреч за неделю ...
└── INDEX.md                                                          ⭐
```

PDF — это полностью оформленный документ с типографикой Calibri, кириллицей, цветными заголовками. Готов к печати или отправке.

### 2. Книга из видеолекций

```
C:\Book\AI\
├── Глава 1 — Введение в нейросети.pdf            (10-12 страниц)
├── Глава 1 — Введение в нейросети.md
├── Глава 2 — Архитектуры LLM.pdf
├── ...
└── BOOK_INDEX.md                                  ← растущее оглавление
```

Каждая глава — это **не пересказ лекции**, а структурированный учебный текст. Claude переработал поток сознания преподавателя в книгу.

### 3. YouTube-метаданные для пачки шортсов

```
C:\Shorts\
├── 01 - Как работает токенизация.MOV
├── 01 - Как работает токенизация-youtube.md       ⭐ готовое к копи-пасту
├── 02 - Почему ChatGPT галлюцинирует.MOV
├── 02 - Почему ChatGPT галлюцинирует-youtube.md
└── ...
```

В `*-youtube.md` уже есть всё, что попросит YouTube-редактор: title, описание, теги, хэштеги, закреплённый комментарий, плюс 4 альтернативных title'а для A/B-тестов через VidIQ.

## Что отличает это от облачных сервисов

Otter.ai, Fireflies, Notta, Plaud Cloud — все они делают похожие задачи. Зачем тогда self-host?

| | Облачный сервис | Plaud Pipeline |
|---|---|---|
| Ваши записи остаются на вашем диске | ❌ Загружаются в облако провайдера | ✅ Только локально |
| Цена за час обработки | $0.10-$1+ | **$0** (если Ollama) или **~$0.01** (если Claude API) |
| Кастомизация шаблонов summary | Ограниченная | Полная — это просто Python-скрипт |
| Работает оффлайн | ❌ | ✅ (с Ollama) |
| Может расшифровать вашу видеолекцию в главу книги | Обычно нет | ✅ |
| Открытый код, можно адаптировать | ❌ | ✅ MIT |

Если у вас 10 встреч в месяц — облако удобнее. Если 100+, или они конфиденциальные, или вам нужен не-стандартный формат — self-host окупится через 2-3 недели.

## Как это работает (за 60 секунд)

```
┌─ Plaud Web ──► JWT из вашего браузера ──┐
│                                          │
├─ Local folder ────────────────────────► │  pull/discover  ►  inbox/
│                                          │
└─ Video lecture (.mov 25 GB) ─► ffmpeg ► │
                                           ▼
                          ┌─────────────────────────────┐
                          │  Whisper (small / medium)   │
                          │  CPU / NVIDIA / Intel iGPU  │
                          └─────────────┬───────────────┘
                                        ▼
                          ┌─────────────────────────────┐
                          │  LLM (Claude/Ollama)        │
                          │  системный промпт →         │
                          │  JSON {title, body_md}      │
                          └─────────────┬───────────────┘
                                        ▼
                          ┌─────────────────────────────┐
                          │  pdf_render — Calibri TTF   │
                          │  ReportLab → PDF + MD       │
                          └─────────────┬───────────────┘
                                        ▼
                          ┌─────────────────────────────┐
                          │  output/<тематическая папка>│
                          │   ├ <safe_title>.pdf        │
                          │   ├ <safe_title>.md         │
                          │   ├ <safe_title>.<ext>      │
                          │   ├ <safe_title>-tr.txt     │
                          │   └ INDEX.md / BOOK_INDEX   │
                          └─────────────────────────────┘
```

Полная архитектура и принципы — [docs/05-architecture.md](docs/05-architecture.md).

## Три железных принципа

1. **Идемпотентность.** Любой скрипт можно перезапустить хоть 100 раз — он пропустит уже сделанное и сделает только новое. Не важно, упало ли соединение, выключили ли свет, добавили ли вы файлы посредине.

2. **Folder-based state.** Никакой базы данных. Никакого скрытого реестра. Состояние = файлы и папки на диске. `.processed.json` в source-папке, `<batch>/SUCCESS` маркер, `-transcript.txt` рядом с аудио. Видно глазами в проводнике, можно поправить руками.

3. **No vendor lock.** SDK Anthropic — лишь один из путей. Не хотите облачный LLM? Поставьте Ollama и переключите флаг `--backend ollama`. Не хотите Anthropic? Можно добавить OpenAI/Mistral/локальный vLLM за полдня — архитектура pull→transcribe→summarise→render→index чистая.

## Истории применения

### «Профессор УрФУ, переработка курса лекций»
Около 30 видеолекций по ИИ за семестр (~50 часов аудио). Запуск `process_lectures.py --openvino` на ноутбуке Intel Arc 140T: ~6 часов работы → 30 глав книги в PDF, общее оглавление, готово отправлять в издательство.

### «Менеджер, ежедневные стендапы»
1-2 встречи в день, 30-45 минут каждая. Plaud записывает в реальном времени, ночью скрипт по cron подтягивает свежие, прогоняет через Whisper и Claude API, к утру в `_Dictophone/Записи за <вчера>` лежат красивые PDF-саммари. **Стоимость**: ~$3/мес за Anthropic API.

### «YouTube-канал "Истории в баре"»
Снято 11 Shorts на iPhone. `process_shorts.py` за 3 минуты сделал транскрипты и для каждого — готовые метаданные с 4 альтернативными title'ами для VidIQ A/B-теста.

## Что НЕ умеет (честный список)

- ❌ **Дидаризация** (разметка кто что сказал). Whisper этого не делает. Можно прикрутить `pyannote.audio`, но не из коробки.
- ❌ **Real-time транскрипция**. Это batch-pipeline, не live-стрим.
- ❌ **Перевод**. Если запись на русском — на выходе русский. Multilingual можно добавить — открывайте PR.
- ❌ **Облачный hosted-режим**. Это локальный pipeline под Windows-ноутбук. Можно завернуть в Docker и крутить на сервере, но из коробки UX заточен под «двойной клик на bat-файл».
- ❌ **Интеграция с Notion/Obsidian/Slack**. Результат — это файлы на диске. Что с ними делать дальше — на ваше усмотрение (Obsidian-vault указанная как `output_dir` работает отлично).
