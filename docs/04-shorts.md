# Pipeline: YouTube Shorts → готовые метаданные

Для контент-мейкеров: вы сняли пачку коротких видео (Shorts/Reels), и нужны цепляющие заголовки, описания, теги, хэштеги и закреплённые комментарии для каждого.

## Минимальный запуск

```bash
python bulk_export/process_shorts.py \
   --source "C:\Shorts\AI" \
   --topic "Как работает ChatGPT" \
   --series "Истории в баре" \
   --openvino
```

Результат — в той же source-папке, рядом с каждым видео:

```
C:\Shorts\AI\
├── IMG_0470.MOV
├── IMG_0470-transcript.txt
├── IMG_0470-youtube.md       ← готовые метаданные
├── IMG_0471.MOV
├── IMG_0471-transcript.txt
├── IMG_0471-youtube.md
└── ...
```

## Что внутри `-youtube.md`

```markdown
# YouTube Shorts — <Заголовок главного варианта>

## 🎯 Hook (первая фраза)
> Первая цитата из видео — для проверки крюка.

## 📢 Заголовок (основной)
**<Цепляющий title>**
_Длина:_ 56 зн.

## 🔄 Альтернативные заголовки (A/B-тесты через VidIQ)
1. <вариант 1>  _(45 зн.)_
2. <вариант 2>  _(50 зн.)_
3. <вариант 3>  _(53 зн.)_
4. <вариант 4>  _(48 зн.)_

## 📝 Описание
<готовый блок для поля Description>

## 🏷 Теги (поле Tags при загрузке)
тег1, тег2, тег3, ...

## #️⃣ Хэштеги (в конце описания)
#Shorts #ИИ #ChatGPT #...

## 💬 Закреплённый комментарий
> Готовый pinned comment с вопросом аудитории.
```

## Аргументы

- `--topic "Тема"` — общая тема серии. Хинт для Claude.
- `--series "Название плейлиста"` — для контекста.
- `--openvino` — использовать Intel iGPU.
- `--skip-whisper` — если transcripts уже готовы.
- `--limit N` — для теста на первых N.

## Логика A/B-вариантов

Claude по умолчанию возвращает **4 альтернативных заголовка**, каждый в своём стиле:
1. Вопрос
2. Число / факт
3. Шок-формулировка
4. Прямой совет

Для A/B-тестирования через VidIQ Insights, Title Tester, или TubeBuddy.

## Идемпотентность

Скрипт пропускает видео, у которого рядом уже есть `<stem>-youtube.md`. Чтобы пересоздать — удалите `youtube.md` файл и запустите снова.

## Промпт

См. `process_shorts.py` → константа `YT_SYSTEM`. Подкрутите под свою нишу (например, добавьте «3 эмодзи в title обязательны» или «всегда start with цифра»).

## Производительность

Типовой 30-секундный Short:
- Извлечение аудио: 1-2 сек.
- Whisper (OpenVINO): 5-10 сек.
- Claude: 5-15 сек.

11 шортсов = ~3-5 минут. Подходит для пакетной обработки всего съёмочного дня.

## Что если сеть нестабильна

Бывает что Claude API возвращает Connection error. Скрипт делает 3 retry, потом пропускает файл. На стабильной сети можно перезапустить позже:

```bash
python process_shorts.py --source "..." --skip-whisper
```

Только новые транскрипты пойдут на Claude.
