# Pipeline: видео-лекции → главы будущей книги

Превращает каждую видеолекцию в полноценную главу учебника. Подходит для:
- Преподавателей, которые хотят переработать курс лекций в книгу.
- YouTube-педагогов, которым нужны конспекты в виде глав.
- Корпоративных тренеров для оформления обучающих материалов.

## Минимальный запуск

```bash
python bulk_export/process_lectures.py --openvino \
   --source "C:\Lectures\AI" \
   --output "C:\Book\AI" \
   --book-title "Курс ИИ для университетов" \
   --book-author "Имя Автора"
```

## Что получается

```
C:\Book\AI\
├── Глава 1 — Введение в нейросети.md
├── Глава 1 — Введение в нейросети.pdf
├── Глава 1 — Введение в нейросети-transcript.txt
├── Глава 2 — Архитектуры LLM.md
├── ...
└── BOOK_INDEX.md       ← растущее оглавление + ссылки на исходники
```

**Видео-оригиналы НЕ копируются** (десятки гигабайт) — в каждой главе и в `BOOK_INDEX.md` есть строка `🎬 Исходник: C:\Lectures\...mov` со ссылкой на исходный файл. Если нужна самодостаточная папка — `--copy-video`.

## Структура главы (от Claude)

```markdown
## Введение
2-4 абзаца — о чём глава и зачем читать.

## Основные идеи

### Идея 1: ...
Подробное раскрытие (2-5 абзацев).

### Идея 2: ...
...

## Примеры и иллюстрации
2-5 конкретных примеров из лекции.

## Ключевые термины
- **Термин 1** — определение.
- **Термин 2** — определение.

## Выводы
3-7 пунктов — что должен запомнить читатель.

## Вопросы для самопроверки
3-7 вопросов на проверку понимания.
```

Промпт см. в `process_lectures.py` → `CHAPTER_SYSTEM`. По умолчанию `max_tokens=16384` — этого хватает на ~10-12 страниц главы.

## Идемпотентность

`.lectures_processed.json` рядом с видео. Добавили новые → обработаются только они → `BOOK_INDEX.md` дорастёт.

## ffmpeg для извлечения аудио

`process_lectures.py` использует встроенный ffmpeg от `imageio-ffmpeg` (ставится через `pip install imageio-ffmpeg`). Системный ffmpeg не требуется.

Формат извлечённого аудио: 16 kHz mono WAV (оптимально для Whisper). Файл идёт в `audio_transcriber/inbox/`, оттуда Whisper его подхватывает.

## Производительность

Типовая 1.5-часовая лекция:

| Шаг | Время на Intel iGPU (OpenVINO) | NVIDIA RTX 5060 Ti |
|---|---|---|
| Извлечение аудио (ffmpeg) | 30 сек | 30 сек |
| Whisper (small) | 12-15 мин | 3-5 мин |
| Claude (sdk) | 15-30 сек | 15-30 сек |
| Render PDF | 1 сек | 1 сек |
| **Всего** | **~15 мин** | **~5 мин** |

## Опции

- `--book-title "..."` — заголовок книги в `BOOK_INDEX.md`.
- `--book-author "..."` — автор там же.
- `--copy-video` — скопировать видео в `book_output` (по умолчанию НЕ копируем — экономим место).
- `--skip-whisper` — re-run только Claude+PDF, transcripts уже готовы.
- `--openvino --device CPU|GPU` — выбрать Intel CPU/iGPU.
- `--backend sdk|cli|ollama|auto`.
- `--limit N` — обработать максимум N файлов (для теста).

## Промпт chapter-режима

Хотите изменить структуру главы (например, добавить «Связь с предыдущей главой» или убрать «Вопросы»)? Откройте `process_lectures.py` → константа `CHAPTER_SYSTEM`. Поменяете один раз — все будущие главы пойдут по новому шаблону.

## Совет: серии и плейлисты

Если у вас несколько курсов, заведите отдельную output-папку для каждого:

```bash
python process_lectures.py --source "C:\Lectures\AI"  --output "C:\Book\AI"  --book-title "Курс ИИ"
python process_lectures.py --source "C:\Lectures\Net" --output "C:\Book\Net" --book-title "Курс сетей"
```

Каждая папка — независимая книга с собственным `BOOK_INDEX.md`.
