# Подключение к Plaud — детальный гайд

Этот гайд расширяет раздел README про получение токена. Объясняет нюансы, типичные ошибки и что делать с двумя учётками.

## Зачем токен, а не email+пароль?

Plaud не предоставляет публичного API. Pipeline имитирует ваш браузер — берёт тот же bearer-токен, который ваш браузер отправляет каждому запросу к `api.plaud.ai` / `api-euc1.plaud.ai`. Это:

- **Безопасно** — никакой пароль не покидает ваш ноутбук.
- **Совместимо со всеми способами входа** — Google SSO, Apple, обычный email/пароль.
- **Не нарушает ToS** — это ваша собственная авторизованная сессия.

В качестве запасного варианта `plaud_export.py` поддерживает `email`/`password` (POST `/auth/access-token`), но **только для обычного email-логина**. SSO-аккаунты — только через токен.

## Где именно находится `tokenstr`

### Chrome / Edge

1. F12 → **Application**
2. Слева раскрыть **Storage → Local Storage → https://web.plaud.ai**
3. Найти ключ `tokenstr`. Иногда вместо него — `access_token`, `token`, `auth_token` (зависит от версии Plaud-фронта). Берите тот, что начинается с `bearer eyJ...` или `eyJ...` и длиной 200+ символов.

### Firefox

1. F12 → **Storage**
2. Слева **Local Storage → https://web.plaud.ai**
3. То же самое.

### Если `tokenstr` нет в Local Storage

Возможно, версия фронта изменилась. Альтернатива:

1. Откройте вкладку **Network** в DevTools.
2. Прокликайте любую запись в Plaud (любая, чтобы вызвался XHR).
3. Найдите запрос к `api.plaud.ai` / `api-euc1.plaud.ai`.
4. В **Headers** → **Request Headers** найдите `Authorization: Bearer eyJ...`.
5. Скопируйте значение после `Bearer ` (без самого слова).

## Формат токена в config.json

Можно с префиксом `bearer ` (с маленькой буквы — Plaud так и хранит) или без него:

```json
"token": "bearer eyJhbGciOi..."
```
или
```json
"token": "eyJhbGciOi..."
```

`plaud_export.py` нормализует оба варианта.

## Регион (`region`)

В JWT-токене зашит регион вашего аккаунта (поле `region: "aws:us-west-2"` или `"aws:eu-central-1"`). Указать в конфиге:

| Регистрация | `region` | Базовый URL |
|---|---|---|
| Северная Америка | `"us"` | `https://api.plaud.ai` |
| Европа | `"eu"` | `https://api-euc1.plaud.ai` |

Если указали неправильно — скрипт получит HTTP 302 и сам перейдёт на правильный URL. Но лучше сразу указать верно — будет на одну сетевую round-trip быстрее.

## Две учётки

Если у вас два Plaud-аккаунта (личный + рабочий, или для разных людей):

```bash
cp config.example.json   config.json     # acc1
cp config_2.example.json config_2.json   # acc2
```

Запускайте раздельно:

```bash
python bulk_export/process_new_plaud_batch.py --account 1
python bulk_export/process_new_plaud_batch.py --account 2
```

Или один `sync_plaud_to_dictophone.py` (если использовать его) проходит по обоим конфигам автоматически.

## Поля `output_dir`, `existing_dir`

```json
"output_dir": "./output",        // куда складывать новые
"existing_dir": "C:\\Archive\\plaud-backup",   // где уже есть выгруженное (skip-set)
```

- `output_dir` — относительный путь от `bulk_export/`, либо абсолютный.
- `existing_dir` — опционально. Если у вас уже есть архив выгруженных ранее transcripts, укажите путь, и скрипт **не будет скачивать** уже имеющиеся (по имени файла). Полезно после миграции архива.

## `mp3_mode`

```json
"mp3_mode": "all"   // также: "off" | "untranscribed"
```

| Значение | Что качает |
|---|---|
| `"off"` | Только `*-transcript.txt` и `*-Summary.txt` от Plaud. Размер ~1 МБ на 100 файлов. |
| `"untranscribed"` | Текст + mp3 только для записей, где Plaud НЕ сделал транскрипт сам. Эти потом расшифровывает локальный Whisper. |
| `"all"` | Текст + mp3 для всех. Десятки гигабайт, но самодостаточный архив. |

Рекомендация для оффлайн-архива: `"all"`. Для лёгкого использования: `"untranscribed"`.

## Что делать при HTTP 401

JWT истёк (живёт ~10 месяцев) или вы вышли из аккаунта на web.plaud.ai. Лекарство:

1. Снова залогиньтесь в Plaud Web.
2. Повторите шаги 1-4 из получения токена.
3. Замените `token` в `config.json`.

Скрипт идемпотентен — повторный запуск докачает только новое.

## Что делать при HTTP 429 (rate limit)

В `config.json` поднимите `sleep_between_files` с `0.3` до `1.0` или `2.0`. Plaud не любит больше ~5 RPS на одного юзера.

## Безопасность токена

- **`.gitignore` уже защищает `config.json`** — он не попадёт в коммит.
- **Не публикуйте токен** в чатах, скриншотах, видео.
- **Не давайте токен ИИ-ассистентам** — они могут случайно его процитировать в выходных артефактах.
- **При утечке** — разлогиньтесь в Plaud Web и снова войдите: старый токен инвалидируется.

## Что делать, если Plaud отключат API

Pipeline ходит на недокументированный API. Plaud в любой момент может его сломать или поменять. План Б:

1. Скрипт `plaud_export.py` написан простым `urllib`, без зависимостей. Адаптировать под новый API — несколько часов работы.
2. Альтернатива — экспорт через Plaud Web-UI вручную (Settings → Export), и затем подача в `process_local_audio.py`.
3. Откройте issue с описанием новой схемы API — сделаем PR.
